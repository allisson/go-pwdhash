# Security Policy

## Supported Versions

Currently, only the latest tagged version is formally supported with security updates. We recommend always keeping your dependencies up to date.

| Version | Supported          |
| ------- | ------------------ |
| v1.x.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of `go-pwdhash` seriously.

If you discover a vulnerability, **please do not open a public issue.**

Instead, please report it privately:
1. Contact the maintainer at contact@allisson.com or through GitHub via Security Advisories (if enabled).
2. We will acknowledge your report within 48 hours.
3. We'll work with you to understand the issue, develop a patch, and coordinate a secure disclosure.

Thank you for helping keep `go-pwdhash` secure!
